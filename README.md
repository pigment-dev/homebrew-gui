# Pigment Dev apps for Homebrew

Mac apps by [Pigment Dev](https://pigment.dev), installed with Homebrew casks.

```sh
brew install --cask pigment-dev/gui/rclone
```

| Cask | App |
|---|---|
| `rclone` | [rClone](https://pigment.dev/products/rclone/): sync Mac folders with Google Drive, OneDrive, Dropbox, S3 and more |

The apps are not signed with an Apple Developer ID yet. If macOS says an app can't be opened, run `xattr -dr com.apple.quarantine "/Applications/<App>.app"`.
